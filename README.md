# Photograp

開源、純瀏覽器執行的圖層式影像編輯器。介面與操作邏輯比照 Photoshop：圖層、遮色片、選取範圍、
混合模式、非破壞性調整圖層、濾鏡與完整的步驟記錄，全部在本機運算，影像不會上傳到任何伺服器。

> An open-source, browser-based raster image editor with layers, masks, selections,
> blend modes, non-destructive adjustment layers, filters and undo history.
> Everything runs locally in the browser — no upload, no server, no account.

## 快速開始

```bash
npm install
npm run dev
```

開啟終端機顯示的網址（預設 <http://localhost:5180>）即可使用。

```bash
npm run build     # 產生 dist/（靜態檔案，可直接用任何靜態主機部署）
npm run preview   # 預覽打包結果
npm run typecheck # TypeScript 嚴格模式檢查
```

測試：啟動 `npm run dev` 後開啟 <http://localhost:5180/tests/index.html>，
81 項核心影像運算測試會直接在瀏覽器中執行並列出結果。

## 功能

### 文件與檔案

- 多文件分頁，各自獨立的縮放、步驟記錄與選取範圍
- 開啟 PNG / JPEG / WebP / GIF / BMP 等瀏覽器支援的格式，可拖放或貼上
- 轉存 PNG / JPEG / WebP，可設定品質與是否以白色填滿透明區
- 專案檔 `.pgraph`（JSON + PNG 圖層資料），完整保留圖層、遮色片、混合模式與選取範圍
- 影像尺寸（重新取樣）、版面尺寸（九宮格錨點）、裁切、修剪透明邊界、旋轉與翻轉

### 圖層

- 點陣圖層、文字圖層、調整圖層、**智慧型物件**、群組
- 24 種混合模式（含畫布未原生支援的線性加深、強烈光、實色疊印、減去、分割等，以逐像素實作）
- 不透明度、鎖定、顯示/隱藏、單獨顯示
- 圖層遮色片：顯示全部 / 隱藏全部 / 由選取範圍建立；可停用、套用或刪除，並以一般筆刷編輯
- 剪裁遮色片、群組、向下合併、合併可見圖層、影像平面化、點陣化
- 圖層樣式：陰影、外光暈、筆畫
- 拖曳重新排序、雙擊重新命名
- 圖層／色版／路徑三個面板以頁籤並排，與 Photoshop 的面板群組一致

### 智慧型物件

- 任何圖層都能轉換為智慧型物件，原始像素會被完整保留
- 縮放、旋轉、翻轉都只改變「放置資料」，畫面隨時從原始來源重新算出，
  縮到 10% 再放回 100% 不會有任何損失（測試以逐位元組比對驗證）
- **智慧型濾鏡**：濾鏡以可編輯的堆疊掛在物件上，隨時調整參數、停用、排序或刪除
- 編輯內容會把來源開成新文件，改完再「儲存回智慧型物件」；也可直接置換為其他影像
- 影像尺寸、版面尺寸、版面旋轉與翻轉都會轉換放置資料而非重新取樣像素

### 路徑與筆型工具

- 筆型工具：點擊建立轉角點、拖曳建立平滑點（控制桿自動鏡射）、
  點回起點封閉路徑、Alt 點擊在平滑點與轉角點之間切換、Backspace 退回上一點
- 直接選取工具：拖曳控制點與控制桿（Alt 可解除連動）、方向鍵微調、Delete 刪除控制點
- 路徑面板：多組具名路徑、縮圖預覽、以前景色填滿、以筆刷描邊、轉換為選取範圍
- 從選取範圍建立工作路徑（輪廓追蹤 + Douglas–Peucker 簡化）
- 作用中的路徑在任何工具下都會顯示

### 色版與快速遮色片

- RGB 複合色版與紅／綠／藍色版，點一下即可單獨檢視為灰階
- Alpha 色版：把選取範圍存成色版、Ctrl 點擊載回選取範圍
- 每個 Alpha 色版可設定疊印顏色與不透明度，疊在影像上檢視
- **快速遮色片 (Q)**：把選取範圍變成可塗抹的灰階通道，
  用黑色遮蔽、白色取消遮蔽，再按一次 Q 轉回選取範圍
- 快速遮色片接管所有繪圖工具，因此筆刷、漸層、油漆桶、濾鏡甚至液化
  都能用來雕琢選取範圍；也可直接存成 Alpha 色版
- 疊印顏色、不透明度與「顏色指示哪一側」都可在選項中調整

### 選取範圍

- 矩形 / 橢圓 / 單列 / 單欄選取，支援固定比例與由中心拖曳
- 套索、多邊形套索、魔術棒（容許度、連續、取樣全部圖層）
- 新增 / 增加 / 減去 / 交集（亦可用 Shift、Alt 即時切換）
- 羽化、擴張、縮減、邊界、平滑、反轉
- 顏色範圍（含即時預視）
- 由圖層透明度或遮色片載入選取範圍
- 動態虛線邊框以輪廓追蹤演算法繪製

### 繪圖與修圖

| 工具 | 說明 |
| --- | --- |
| 筆刷 / 鉛筆 | 尺寸、硬度、不透明度、流量、間距、平滑化、散佈、壓力感應 |
| 橡皮擦 | 在遮色片上自動改為以背景色塗抹 |
| 仿製印章 | Alt 設定來源，可對齊 / 不對齊、取樣全部圖層 |
| 指尖 | 依筆觸方向推抹像素 |
| 模糊 / 銳利化 | 局部套用高斯模糊或卷積銳利化 |
| 加亮 / 加深 / 海綿 | 可選陰影、中間調、亮部範圍 |
| 油漆桶 | 容許度、連續、擴張邊緣、取樣全部圖層 |
| 漸層 | 線性、放射狀、角度、反射、菱形，六組預設與反轉、混色 |
| 形狀 | 矩形、圓角矩形、橢圓、直線、箭頭、多邊形、星形 |
| 文字 | 畫布上直接編輯，可設字體、大小、粗斜體、對齊、字距、行距、顏色 |
| 筆型 / 直接選取 | 貝茲路徑繪製與控制點編輯 |
| 裁切 | 固定比例、三分構圖線、遮蔽裁切區外 |
| 任意變形 | 縮放、旋轉、翻轉，對角固定，Alt 由中心縮放 |
| 滴管 / 手形 / 縮放 | 取樣大小、空白鍵暫時平移、拖曳框選縮放 |

所有筆刷類工具的筆觸會先累積在暫存層，再以「筆觸不透明度」一次合成到圖層，
因此同一筆內重疊處不會越疊越深，與 Photoshop 的行為一致。

### 調整與濾鏡

- **調整**（可作為破壞性調整或非破壞性調整圖層）：亮度/對比、色階、曲線、曝光度、
  自然飽和度、色相/飽和度、色彩平衡、黑白、相片濾鏡、色版混合器、漸層對應、
  負片效果、色調分離、臨界值
- 曲線提供可拖曳控制點的編輯器（單調三次內插，不會過衝），色階附直方圖
- **濾鏡**：高斯 / 方框 / 動態 / 放射狀 / 表面模糊、銳利化、遮色片銳利化調整、高反差保留、
  扭轉、漣漪、波浪、魚眼、旋轉效果、浮雕、尋找邊緣、油畫、擴散光暈、暈映、自訂卷積、
  增加雜訊、中間值、馬賽克、結晶化、雲彩
- **液化 (Ctrl+Shift+X)**：獨立的變形工作區，以位移網格推擠像素
  - 向前彎曲、順時針／逆時針扭轉、縮攏、膨脹、左推、重建
  - 凍結遮色片保護不想被影響的區域，可隨時解凍
  - 預覽在縮小的副本上即時運算，確定後才以同一張網格在原尺寸重跑一次
  - 可顯示變形網格；也能直接對圖層遮色片或快速遮色片液化
- 對話框皆有即時預視，且只計算選取範圍的外接矩形，大圖也能順暢操作
- 自動色調、自動對比

### 檢視

- 1% ～ 3200% 縮放、Ctrl+滾輪以游標為中心縮放、顯示全頁、實際尺寸
- 尺標、格點、超高倍率時的像素格線、導覽器縮圖與可視範圍框
- 透明區棋盤格、畫布投影

## 專案結構

```
src/
  core/       文件模型：圖層、選取範圍、遮色片、快速遮色片、路徑、
              色版、智慧型物件、混合、合成、步驟記錄
  filters/    調整（LUT/逐像素）與濾鏡（模糊、卷積、扭曲、演算）
  tools/      工具實作與共用的筆觸引擎
  io/         開檔、轉存、.pgraph 專案序列化
  ui/         選單、工具列、選項列、畫布檢視、面板、對話框
tests/        瀏覽器測試頁（81 項核心運算測試）
docs/         架構說明
```

架構細節與擴充方式請見 [docs/architecture.md](docs/architecture.md)。

## 技術說明

- TypeScript 5，`strict` 模式；打包工具 Vite
- **執行期零相依套件**：所有影像運算皆自行實作，只用 HTML5 Canvas 2D 與型別化陣列
- 圖層像素採用寫入時複製（copy-on-write）：步驟記錄的快照共用未變動的緩衝區，
  只有被修改的圖層才會佔用額外記憶體
- 遮色片以「不透明灰階」儲存，合成時才轉成 alpha（結果會快取），
  因此可以用一般的筆刷工具直接編輯遮色片

## 瀏覽器需求

需支援 `createConicGradient`、`ResizeObserver` 與 Canvas 混合模式的現代瀏覽器：
Chrome / Edge 110+、Firefox 110+、Safari 16.4+。
