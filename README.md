# Photograp

開源、純瀏覽器執行的圖層式影像編輯器。介面與操作邏輯比照 Photoshop：圖層、遮色片、選取範圍、
混合模式、非破壞性調整圖層、濾鏡與完整的步驟記錄，全部在本機運算，影像不會上傳到任何伺服器。

> An open-source, browser-based raster image editor with layers, masks, selections,
> blend modes, non-destructive adjustment layers, filters and undo history.
> Everything runs locally in the browser — no upload, no server, no account.

## 快速開始

```bash
npm install
npm run dev
```

開啟終端機顯示的網址（預設 <http://localhost:5180>）即可使用。

```bash
npm run build     # 產生 dist/（靜態檔案，可直接用任何靜態主機部署）
npm run preview   # 預覽打包結果
npm run typecheck # TypeScript 嚴格模式檢查
```

測試：啟動 `npm run dev` 後開啟 <http://localhost:5180/tests/index.html>，
231 項核心影像運算測試會直接在瀏覽器中執行並列出結果。

## 功能

### 文件與檔案

- 多文件分頁，各自獨立的縮放、步驟記錄與選取範圍
- 開啟 PNG / JPEG / WebP / GIF / BMP 等瀏覽器支援的格式，可拖放或貼上
- 轉存 PNG / JPEG / WebP，可設定品質與是否以白色填滿透明區
- 專案檔 `.pgraph`（JSON + PNG 圖層資料），完整保留圖層、遮色片、混合模式與選取範圍
- 影像尺寸（重新取樣）、版面尺寸（九宮格錨點）、裁切、修剪透明邊界、旋轉與翻轉

### 圖層

- 點陣圖層、文字圖層、**向量形狀圖層**、調整圖層、**智慧型物件**、群組
- 24 種混合模式（含畫布未原生支援的線性加深、強烈光、實色疊印、減去、分割等，以逐像素實作）
- 不透明度、鎖定、顯示/隱藏、單獨顯示
- 圖層遮色片：顯示全部 / 隱藏全部 / 由選取範圍建立；可停用、套用或刪除，並以一般筆刷編輯
- 剪裁遮色片、群組、向下合併、合併可見圖層、影像平面化、點陣化
- 圖層樣式：陰影、外光暈、筆畫
- 拖曳重新排序、雙擊重新命名
- **搜尋與篩選**：面板上方可依名稱搜尋（不分大小寫），
  也可依類型篩選（點陣 / 文字 / 形狀 / 智慧型物件 / 調整 / 群組 / 有樣式 / 有遮色片）；
  群組內有任一子圖層命中就會一併保留，不會把結果藏起來
- 圖層／色版／路徑／筆刷四個面板以頁籤並排，與 Photoshop 的面板群組一致

### 智慧型物件

- 任何圖層都能轉換為智慧型物件，原始像素會被完整保留
- 縮放、旋轉、翻轉都只改變「放置資料」，畫面隨時從原始來源重新算出，
  縮到 10% 再放回 100% 不會有任何損失（測試以逐位元組比對驗證）
- **智慧型濾鏡**：濾鏡以可編輯的堆疊掛在物件上，隨時調整參數、停用、排序或刪除
- 編輯內容會把來源開成新文件，改完再「儲存回智慧型物件」；也可直接置換為其他影像
- 影像尺寸、版面尺寸、版面旋轉與翻轉都會轉換放置資料而非重新取樣像素

### 文字沿路徑

- 用文字工具點在作用中的路徑上（距離 10px 內），打出來的字就會沿著曲線走；
  也可以對現有的文字圖層執行「圖層 › 文字 › 使文字沿路徑」（路徑面板下方也有按鈕）
- 每個字形都放在自己字寬的中間並依当地切線旋轉，所以轉彎時字依然是站直的，
  不會整段被斜切
- 對齊方式決定文字在路徑上的位置（靠左＝起點、置中、靠右＝終點），
  再加上可調的**起點位移**與**基線位移**，並可**翻轉**到曲線另一側
  （圓圈內側的文字就是靠這個）
- 用移動工具拖曳時，拖曳會在抱住的點拆成「沿曲線」與「離開曲線」兩個分量，
  分別改變起點與基線位移
- 用直接選取工具改路徑時，文字會即時跟著曲線走；影像尺寸、版面尺寸與
  旋轉翻轉也會同步搬動儲存的路徑
- 路徑上只有一條基準線，因此換行會折成空白；文字比路徑長時會沿著端點的
  切線繼續延伸，而不是消失
- 像素是從路徑算出來的，所以跟形狀圖層一樣不能直接筆刷，需要時先「點陣化圖層」

### 向量形狀圖層

- 形狀工具 (`U`) 預設畫出的是**形狀圖層**，而不是像素；
  選單列也保留「填滿像素」選項，行為跟以前一樣
- 矩形、圓角矩形、橢圓、直線、箭頭、多邊形、星形都會轉成貝茲路徑，
  橢圓以四個平滑點近似（控制桿長度 0.5523r）
- 畫完之後仍然**可再編輯**：直接選取工具 (`A`) 會自動作用在形狀圖層本身的路徑上，
  拖曳控制點、方向鍵微調、Delete 刪除點，圖層會即時重新描繪
- 「圖層 › 形狀選項…」（或雙擊面板上的形狀縮圖）可調填色、筆畫顏色與寬度、
  各自的不透明度、筆畫對齊（置中 / 內部 / 外部）、虛線、轉角與端點，
  對話框即時預視，取消會還原
- 移動工具與任意變形也是搬動控制點（變形時筆畫寬度跟著縮放），
  所以調完位置後仍然可以繼續編輯路徑
- 像素是幾何算出來的結果，所以不能直接在形狀圖層上筆刷（跟智慧型物件一樣），
  工具會提醒先「點陣化圖層」
- 影像尺寸、版面尺寸、旋轉與翻轉都是搬動**控制點**而不是重新取樣像素，
  放大再縮小不會變模糊；縮放時筆畫寬度也會跟著等比調整
- 形狀幾何與樣式會存進專案檔與步驟記錄；需要像素時隨時可以「點陣化圖層」

### 路徑與筆型工具

- 筆型工具：點擊建立轉角點、拖曳建立平滑點（控制桿自動鏡射）、
  點回起點封閉路徑、Alt 點擊在平滑點與轉角點之間切換、Backspace 退回上一點
- 直接選取工具：拖曳控制點與控制桿（Alt 可解除連動）、方向鍵微調、Delete 刪除控制點
- 路徑面板：多組具名路徑、縮圖預覽、以前景色填滿、以筆刷描邊、轉換為選取範圍
- 從選取範圍建立工作路徑（輪廓追蹤 + Douglas–Peucker 簡化）
- 作用中的路徑在任何工具下都會顯示

### 色版與快速遮色片

- RGB 複合色版與紅／綠／藍色版，點一下即可單獨檢視為灰階
- Alpha 色版：把選取範圍存成色版、Ctrl 點擊載回選取範圍
- 每個 Alpha 色版可設定疊印顏色與不透明度，疊在影像上檢視
- **快速遮色片 (Q)**：把選取範圍變成可塗抹的灰階通道，
  用黑色遮蔽、白色取消遮蔽，再按一次 Q 轉回選取範圍
- 快速遮色片接管所有繪圖工具，因此筆刷、漸層、油漆桶、濾鏡甚至液化
  都能用來雕琢選取範圍；也可直接存成 Alpha 色版
- 疊印顏色、不透明度與「顏色指示哪一側」都可在選項中調整

### 選取範圍

- 矩形 / 橢圓 / 單列 / 單欄選取，支援固定比例與由中心拖曳
- 套索、多邊形套索、魔術棒（容許度、連續、取樣全部圖層）
- 新增 / 增加 / 減去 / 交集（亦可用 Shift、Alt 即時切換）
- 羽化、擴張、縮減、邊界、平滑、反轉
- 顏色範圍（含即時預視）
- 由圖層透明度或遮色片載入選取範圍
- 動態虛線邊框以輪廓追蹤演算法繪製

### 調整與濾鏡

- **調整**（可作為破壞性調整或非破壞性調整圖層）：亮度/對比、色階、曲線、曝光度、
  自然飽和度、色相/飽和度、色彩平衡、黑白、相片濾鏡、色版混合器、
  **選取顏色**、漸層對應、**陰影/亮部**、負片效果、色調分離、臨界值
- **選取顏色**把像素分到九個顏色家族（紅黃綠青藍洋紅加上白、中間調、黑），
  再在選中的家族裡加減 CMYK；「相對」縮放原本就有的墓量，
  「絕對」直接加上固定量（所以純紅這種沒有青墓的顏色，相對方式不會改變它）
- **陰影/亮部**拉回暗部細節並壓低過亮的區域，附色調範圍、中間調對比與顏色校正；
  提亮是按比例放大，所以黑點會保留、不會把黑色洗成灰色
- 曲線提供可拖曳控制點的編輯器（單調三次內插，不會過衝），色階附直方圖
- **濾鏡**：高斯 / 方框 / 動態 / 放射狀 / 表面模糊、銳利化、遮色片銳利化調整、高反差保留、
  扭轉、漣漪、波浪、魚眼、旋轉效果、浮雕、尋找邊緣、油畫、擴散光暈、暈映、自訂卷積、
  增加雜訊、中間值、馬賽克、結晶化、雲彩
- **液化 (Ctrl+Shift+X)**：獨立的變形工作區，以位移網格推擠像素
  - 向前彎曲、順時針／逆時針扭轉、縮攏、膨脹、左推、重建
  - 凍結遮色片保護不想被影響的區域，可隨時解凍
  - 預覽在縮小的副本上即時運算，確定後才以同一張網格在原尺寸重跑一次
  - 可顯示變形網格；也能直接對圖層遮色片或快速遮色片液化
- 對話框皆有即時預視，且只計算選取範圍的外接矩形，大圖也能順暢操作
- 自動色調、自動對比

### 筆刷預設集

- 面板中內建九組筆刷（柔邊 / 硬邊圓形、鉛筆、噴槍、書法筆、粉筆、噴濺、細線、大面積柔邊），
  每一項都以實際筆尖畫出的筆觸縮圖呈現，一眼就看得出特性
- 點一下套用到目前的繪圖工具；工具沒有的選項（例如橡皮擦沒有散佈）會自動略過
- 可把目前的筆刷設定存成自訂預設集，並重新命名、刪除或恢復成內建組合
- 自訂內容存在瀏覽器的 localStorage，重新整理後仍在
- 筆尖新增**圓度**與**角度**，把圓筆變成書法用的扁筆；另有**尺寸快速變換**做出自然的顆粒感

### 修復與內容感知填色

- **汙點修復筆刷 (J)**：塗過瑕疵就好。工具會在附近找一塊材質最接近的區域，
  貼過來之後再用無縫貼合（Poisson）把接縫溶掉，所以不會留下硬邊或亮度斷層
- **修復筆刷**：Alt 點選來源，保留來源的紋理但自動接上目標的亮度與色調
- 整筆畫完才一次修復，而不是邊拖邊補，這樣接縫才會平順
- **內容感知填色 (`Shift+Backspace`)**：用周圍的影像重新合成選取範圍，
  多尺度 PatchMatch 會延續紋理與結構，適合移除畫面中不要的物件
- 可調品質、結構細節與選取範圍擴張量；只處理破洞周圍的視窗，
  所以成本取決於選取範圍大小而不是整張影像

### 參考線與靠齊

- 從尺標往畫面拖曳即可建立參考線；移動工具可再拖動，拖出畫布外就刪除
- 可鎖定參考線、由選取範圍一次建立四條、或用對話框輸入精確位置
- **靠齊**（`Ctrl+Shift+;`）可分別開關「參考線 / 格點 / 文件邊界 / 圖層」
- 移動圖層時會以邊緣與中心線去對齊，裁切框與選取畫面則對齊拖曳中的邊
- 命中時畫面會顯示洋紅色的靠齊指示線；拖曳中按住 `Ctrl` 可暫時停用靠齊
- 參考線會隨版面尺寸位移、隨影像尺寸等比例縮放，並存入專案檔與步驟記錄

### 選取並遮住

- 「選取 › 選取並遮住…」(`Ctrl+Alt+R`) 是帶即時預視的調整邊緣工作區
- 四組調整依序套用：**平滑**（磨掉鎖齒狀邊緣與雜訊）、**羽化**、
  **對比**（把羽化過的邊緣拉回來）、**移動邊緣**（往外擴張或往內收縮）
- 五種檢視模式：疊印紅色、黑底、白底、透明背景、遮色片，
  方便判斷邊緣在不同背景下的樣子
- 可以輸出回**選取範圍**、直接變成**圖層遮色片**，或剪成**新圖層**
- 預視在縮小的副本上即時運算（半徑同比例縮放），確定後才以原尺寸重跑一次

### 漸層編輯器

- 選項列上的漸層縮圖點一下就開啟編輯器，跟 Photoshop 一樣
- 漸層條下方是**色標**、上方是**不透明度色標**；點漸層條新增色標（顏色會取
  當下的內插值，所以漸層不會跳掉）、拖曳可移動、雙擊可換色
- 每個色標可以是固定顏色，也可以**跟隨前景色或背景色**，
  內建的「前景到背景」就是靠這個做的
- 可以命名存成自訂漸層，存在瀏覽器的 localStorage，重新整理後仍在；
  隨時可以刪除單一自訂漸層或一鍵恢復內建

### 對齊與分佈

- 「圖層 › 對齊與分佈」可把作用中的圖層靠左/置中/靠右、靠上/置中/靠下
- **有選取範圍時對齊到選取範圍，沒有則對齊到畫布**
- 平均分佈作用於同層級的可見圖層（至少三個），把間距拉成一致；
  填滿整張畫布的底圖不列入計算，因為它沒有可分佈的位置
- 群組會帶著子圖層一起移動；形狀圖層的位移會折入控制點，
  沿路徑的文字則會說明要改路徑或起點位移

### 步驟記錄快照與步驟記錄筆刷

- 步驟記錄面板可以把目前狀態**存成具名稱的快照**（面板右上的相機圖示，
  或「編輯 › 建立快照…」）。快照不算一個步驟，也不會被 50 步的滾動上限擠掉；
  點一下就回到那個狀態，而且這個回到本身也能再還原
- 每一列左邊的方塊是**步驟記錄筆刷的來源**，沒指定時預設是最舊的那一步
- **步驟記錄筆刷 (Y)**：把刷過的地方畫回來源狀態的樣子，等於把「局部還原」
  變成一支筆；尺寸改過、或來源狀態裡沒有這個圖層時會明確拒絕而不是隨便畫
- **「編輯 › 填滿步驟記錄」**：一次把選取範圍（沒選取則整層）換成來源狀態的像素

### 色階分佈圖

- 面板隨時顯示明度或紅 / 綠 / 藍單一色版的分佈，來源可切換「合併影像」或「目前圖層」
- 同時列出平均值、標準差、中間值、像素數與最暗 / 最亮值，完全透明的影像不會除以零
- 結果以文件版本快取，面板收起時不做任何運算，所以不會拖慢筆刷

### 檢視

- 1% ～ 3200% 縮放、Ctrl+滾輪以游標為中心縮放、顯示全頁、實際尺寸
- 尺標、格點（間距可調）、超高倍率時的像素格線、導覽器縮圖與可視範圍框
- 透明區棋盤格、畫布投影

## 技術說明

- TypeScript 5，`strict` 模式；打包工具 Vite
- **執行期零相依套件**：所有影像運算皆自行實作，只用 HTML5 Canvas 2D 與型別化陣列
- 圖層像素採用寫入時複製（copy-on-write）：步驟記錄的快照共用未變動的緩衝區，
  只有被修改的圖層才會佔用額外記憶體
- 遮色片以「不透明灰階」儲存，合成時才轉成 alpha（結果會快取），
  因此可以用一般的筆刷工具直接編輯遮色片

## 瀏覽器需求

需支援 `createConicGradient`、`ResizeObserver` 與 Canvas 混合模式的現代瀏覽器：
Chrome / Edge 110+、Firefox 110+、Safari 16.4+。
